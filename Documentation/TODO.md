Membuat Aplikasi Form Web PHP (Prioritas Utama / Urgent)
Tugas ini harus diselesaikan lebih awal. Atasan meminta pembuatan form digital yang berfungsi mirip Google Forms namun dibangun secara kustom menggunakan PHP.
| Fitur/Komponen | Spesifikasi & Keterangan |
|---|---|
| Platform | Aplikasi web PHP satu halaman (sederhana, tidak perlu rumit). |
| Dukungan Bahasa | Bilingual (mendukung Bahasa Inggris dan Bahasa Indonesia). |
| Input Data | Memuat kolom pengisian seperti Nama Pasien (Patient Name), NRIC, Alamat, dan opsi checklist. |
| Tanda Tangan | Wajib memiliki fitur Digital Signature agar pengguna bisa tanda tangan langsung di layar (HP/Tablet). |
| Database | Tidak menggunakan database server fisik/terpisah. Gunakan local storage atau SQLite. |
| Output/Ekspor | Setelah form di-submit, data otomatis masuk ke database dan dapat diekspor menjadi dokumen PDF. |
